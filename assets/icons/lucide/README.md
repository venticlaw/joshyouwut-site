# Player Control Icons

Six unchanged SVG files copied from the official `lucide-static` npm package, version 1.79.0, exact source paths `icons/play.svg`, `icons/pause.svg`, `icons/skip-back.svg`, `icons/skip-forward.svg`, `icons/x.svg`, and `icons/sliders-horizontal.svg`.

The package LICENSE is retained beside the assets: Lucide ISC terms and the included MIT terms for listed Feather-derived icons. The package is not a site runtime dependency. Combined SVG payload: 2,444 bytes before compression. Files were inspected for scripts, foreign objects and external references; none are present. Controls have native buttons/ranges and accessible names in the page; decorative SVGs are hidden from assistive technology. CSS masks include the WebKit form for Safari compatibility.
